> [!claim] 项目定位
> Crossref（早期写作 CrossRef，法权主体为国际出版商联合会 Publishers International Linking Association, Inc., PILA）是 2000 年由国际主要学术出版商联合发起设立的非营利性学术元数据清算机构与国际数字对象标识符基金会（International DOI Foundation, IDF）官方注册代理。Crossref 旨在建立跨出版商的开放参考文献持久链接系统，现已拓展为覆盖期刊出版物、学术专著、会议录、预印本、研究资助及数据集的全球综合学术元数据基础设施。[[Argument_Lin_2023_SciData|(Lin et al., 2023)]]; [[Argument_Liu_2023_NHB|(Liu et al., 2023)]]

> [!program-context] 项目背景
> - **立项时间 / 周期** 1999 年由学术出版商发起筹备，2000 年 1 月正式成立 PILA 并上线 DOI 参考文献交叉链接服务，常态化持续运营至今。
> - **发起方与资助机制** 由多家国际学术出版机构共同创建，实行会员制非营利治理；经费依托出版商缴纳的年度会员费与 DOI 注册按量收费，面向全球公众与科研群体免费开放元数据应用程序接口（Application Programming Interface, API）。
> - **覆盖范围与对象** 截至 2020 年代收录来自全球 140 多个国家与地区、超过 20,000 家学术出版机构与学术学会提交的逾 1.5 亿条记录，涵盖期刊成果、专著章节、学术专著、预印本与资助项目。
> - **核心问题导向** 消除传统学术出版领域各出版商网站相互隔离导致的断链与网址失效危机（Link Rot），通过持久解析与标准化元数据交换确立开放科学互操作性标准。

> [!claim] 核心干预／机制假说
> 通过建立去中心化会员共享的 DOI 持久解析机制与标准化的开放机器可读元数据交换规范，能够消除学术文献跨出版平台的引证割裂，为全球[[Literature Search|文献检索]]、跨源[[Record Linkage|记录链接]]与科技评价提供通用、免版权壁垒的客观证据底网。[[Argument_Lin_2023_SciData|(Lin et al., 2023)]]

> [!policy-design] 方案设计
> - **项目目标** 实现全学科、跨出版商数字学术资源的一击直达互联，维护数字对象持久标识、版本演化历史与科研资助血统网络。
> - **覆盖对象** 同行评议学术期刊出版物、学术专著与章节、会议文集、预印本服务器成果、学术数据集及公共资助项目编号。
> - **干预措施** 
>   - **DOI 注册与持久解析** 为每一篇学术出版物分配全球唯一的 DOI 标识，强制出版商在文献末尾将参考文献解析至目标 DOI。
>   - **Crossmark 版本状态更新** 跟踪成果的修正（Corrigenda）、勘误（Erratum）与撤稿（Retraction）时序轨迹。
>   - **Funder Registry（FundRef）资助对齐** 提供标准化科研基金资助机构受控词表，汇集项目立项编号与文献关联。
>   - **Crossref Event Data** 捕捉学术成果在维基百科、推特、网络博客及主流新闻媒体中的多源注意力痕迹。
> - **实施控制** 建立会员准入审查与元数据 schema 机器校验规则，要求存缴机构持续更新 URL 映射以规避失效链接。

> [!citation-card] PILA 倡议论学术文献持久交叉链接
> 电子出版的根本价值在于即时穿透引用网络。通过跨越各商业机构与学会边界的互惠协作协议，Crossref 建立起独立于单一平台的开放解析中枢，确保学者无论在何处阅读文献，皆可通过一条持久链接直抵被引源头。(PILA Charter, 2000)
>
> *Scholarly publishing is strengthened when researchers can navigate seamlessly across publishers... By creating a cooperative, cross-publisher reference linking system through Digital Object Identifiers, Crossref ensures persistent intellectual connections independent of platform changes.*

> [!dev-timeline] 项目推进历程
> - **2000 — 联合会成立与 DOI 交叉链接体系启动** 出版商联合会（PILA）正式注册，联合上线参考文献跳转服务，首年完成数百万篇期刊成果的 DOI 编目与链接打通。
> - **2008–2012 — 资助流向追踪与出版诚信模块确立** 推出 FundRef 基金注册体系，统一全球科研资助机构名称编码；发布 Crossmark 标识，建立同行评议文献后续版本修订与撤稿追踪的标准接口。
> - **2017 — 替代计量数据流 Crossref Event Data 上线** 启动开放事件数据服务，脱敏聚合全球社交媒介、学术博客与公共百科中围绕 DOI 展开的数字化讨论，为大规模[[Altmetrics|替代计量学]]研究开辟官方公共数据管道。
> - **2023 — 支撑亿级科学学开放数据湖工程** 在林子敬（Zijing Lin）等构建的 SciSciNet 数据湖中，Crossref 成为外部资助校验与社交媒体引流的关键基础设施：通过 Crossref 基金库记录补齐 305,314 条资助关系，并通过 Crossref Event API 接入 5,584 万条推特讨论与 59.5 万条全球主流媒体新闻报道提及。[[Argument_Lin_2023_SciData|(Lin et al., 2023)]]

> [!actor-grid] 实施协同矩阵
> - **发起与治理机构** PILA 董事会（由大学出版社、商业出版商及学术学会代表共同组成），负责技术治理标准制定与会员准入规则。
> - **注册代理与架构维护团队** Crossref 技术工程团队，负责维护高可用元数据收录引擎、REST API 与 OAI-PMH 数据收割接口。
> - **成员出版机构** 全球各大学术期刊出版商、大学出版社与机构知识库，负责按标准 schema 上传结构化元数据并缴纳年费。
> - **受益群体与终端应用** 全球图书情报机构、数据聚合平台（OpenAlex、Dimensions、SciSciNet）、科学学研究团队及社会公众。

> [!pathways] 实施路径与管理
> - **纵向传导与支持** 制定强制性元数据存缴规范（强制要求篇名、出版时间、参考文献列表及 DOI 绑定），通过开发者文档与自动化校验接口辅导中小型出版机构合规接入。
> - **横向跨部门协同** 与国际 DOI 基金会（IDF）、数据引用联盟（DataCite）及研究机构识别符（Research Organization Registry, ROR）保持互操作性协议协同，实现成果、学者、机构与资助多维实体的交叉映射。
> - **动态反馈与调整** 针对部分出版商仅存缴基础引证而扣留完整参考文献的壁垒现象，联合开放引文倡议（Initiative for Open Citations, I4OC）推动参考文献元数据 100% 免许可无偿开放。

> [!indicators] 评估指标体系
> - **标识规模指标** 注册 DOI 总数、覆盖的出版物总量及按年度递增的数字对象存缴率。
> - **关系网络密度指标** 存缴完整参考文献记录的成果占比、关联科研资助（Grant ID）成果占比与版本修正（Crossmark）匹配率。
> - **数据开放性与调用量** REST API 日均访问查询吞吐量、全量元数据公共数据转储（Public Data File）下载频次。

> [!finding-cards] 核心功能特征
> - **中立非营利的开放数据源** 不设立专有版权护城河，元数据遵循知识共享许可协议（CC0）向全球学术共同体免费开放，成为开放科学知识发现的基础支柱。
> - **多源跨界应用转化的纽带** 打破传统期刊孤岛，将学术成果向上游公共资金（FundRef）与下游社交媒介讨论（Event Data）有效锚定。
> - **实体对齐的核心锚点** 在科学学大规模数据清洗与[[Record Linkage|记录链接]]中，DOI 是连接多源异构数据库最可靠的黄金主键。

> [!stat-cards]- 关键实证数据
> - **150M+** 平台累积托管的全球学术数字对象（DOI）总量。
> - **20K+** 接入系统的全球出版机构与学术学会会员总量。
> - **55.8M+** 在 SciSciNet 中通过 Crossref Event Data 对齐的推特社交讨论条目数。[[Argument_Lin_2023_SciData|(Lin et al., 2023)]]
> - **305K+** 在 SciSciNet 中依托 Crossref 基金库补充的精准公共资助关系记录数。[[Argument_Lin_2023_SciData|(Lin et al., 2023)]]

> [!debates] 核心争议
>
> > [!axis] 元数据质量不均衡 vs 开放通用性
> > 针对中小型出版商存缴元数据字段缺失与结构混乱的讨论。
> >
> > - **批评观点** 由于 Crossref 采取包容性会员准入，不同出版机构上传的字段完整度参差严重，早期大量文献缺乏规范参考文献列表与学者机构 ROR 标识，给下游科学计量带来二次清洗负担。
> > - **回应辩护** Crossref 坚持公共基础设施中立定位，通过升级自动质量评分与强化元数据激励政策，逐步提升全库字段丰度，避免将非英语及边缘地区小型学术刊物排斥于国际知识网络之外。
>
> > [!axis] 商业出版联盟属性 vs 完全开放科学伦理
> > 针对其由传统商业出版寡头主导发起的治理合法性争鸣。
> >
> > - **批评观点** 批评者指出 PILA 早期受制于大型商业出版集团的商业利益，推行开放参考文献元数据的步伐长期滞后。
> > - **回应辩护** 随着开放获取运动深化，Crossref 已于 2022 年实现全量参考文献元数据面向全球无条件开放，彻底确立了其作为开放科学公域资产的制度定位。
