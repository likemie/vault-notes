# Callouts

本文件是组件速查表，按**想表达的内容类型**分组，而不按页面类型分组。具体视觉样式见 `argument-callouts.css`。

---

## 使用原则

- callout 服务阅读层次。普通说明段不要强行包进 callout。
- 同一节内 callout 不宜过密；内容少于 3 点时优先用散文或普通列表。
- 任何 callout 可加 `+`/`-` 控制折叠，例如 `[!stat-cards]-`。
- 嵌套不超过 2 层。列表项内嵌套用 `>    > [!type]`（外层 `>` + 3 空格）。
- Mermaid 节点标签保持单行；流程图默认 `flowchart LR`。

## 提问与主张

| Callout | 用途 |
|---|---|
| `[!question]` | 研究问题、经验谜题、核心关切 |
| `[!claim]` | 可争辩判断；不写材料描述 |
| `[!warrant]` | 证据与主张之间的推理桥梁；解释"为什么证据能支持主张" |
| `[!abstract]` | 核心主张摘要、理论框架、章节结构 |
| `[!implication]` | 发现或论证的理论、方法和实践后果 |
| `[!conclusion]` | 论证结论或批评裁定 |
| `[!tension]` | 理论张力、对立立场、争议焦点 |

## 定义与概念

| Callout | 用途 |
|---|---|
| `[!info]` | 定义、背景、前提条件 |
| `[!def]` | 突出核心定义和边界 |
| `[!term]` | 短定义或名称辨析 |
| `[!boundary]` | 适用范围、排除条件 |
| `[!concept-lens]` | 概念的含义、用途和边界三联透镜 |
| `[!exegesis]` | 抽象概念或论证步骤的解释性补充，常配教育例子 |
| `[!theory-stance]` | 认识论与方法含义；必须写"不能直接推出的东西" |

## 论证结构与推理图

| Callout | 用途 |
|---|---|
| `[!logic-map]` | Mermaid 论证图、机制图、因果链 |
| `[!mechanism-map]` | 理论机制图；图后需配 `[!proposition-chain]` 或散文解释 |
| `[!proposition-chain]` | 核心命题链，按前提 → 机制 → 条件 → 结果组织 |
| `[!argument-steps]` | 分步论证结构，适合全书或长篇论证 |
| `[!chain-link]` | 独立"证据 → 分析 → 结论"链节，各块应自足 |
| `[!assumptions]` | 层层递进的理论假设或前提 |
| `[!axioms]` | 公理化前提或不可再拆的基础命题 |

## 数据与发现

| Callout | 用途 |
|---|---|
| `[!stat-cards]` | 样本量、比例、效应量、关键数字 |
| `[!finding-cards]` | 不超过四条核心发现 |
| `[!success]` | 主要发现、影响、效果 |
| `[!evidence-grid]` | 多点并列证据；列表或表格均可 |
| `[!evidence-grid-a]` | 第一组主题证据，常与 b 对照 |
| `[!evidence-grid-b]` | 第二组主题证据，常与 a 对照 |
| `[!effect-table]-` | 效应量汇总表（研究 / 样本 / 前测 / 后测 / d / SE / CI / 结论） |
| `[!ma-table]-` | 元分析汇总表（研究 / N / d / SE / 95%CI / Q / 结论） |

## 比较与并列

| Callout | 用途 |
|---|---|
| `[!contrast-table]` | 概念辨析、案例对比、理论路径对比；必须有明确比较维度 |
| `[!line-a]` | 蓝色自动编号线索框（A → B → C…），连续使用时序号自动递增 |
| `[!line-b]` | 红色对照线索框，紧接 `[!line-a]` 形成上下对比；不单独出现 |
| `[!col-l]` + `[!col-r]` | 父 callout 内两个并列子主题 |
| `[!quad-grid]` | 恰好 4 项且权重相当的类型、案例或框架 |
| `[!frames-ref]` | 固定数量的框架、原则或要点，适合 6–12 项 |
| `[!actor-grid]` | 行动者或利益相关者 2×2 网格 |
| `[!prop-table]-` | 行动者属性表（行动者 / 资源类型 / 核心利益 / 立场 / 策略） |

|---|---|
| `[!example]` | 案例、教育情境例子、图表占位 |
| `[!case]` | 独立政策或实证案例 |

| `[!pathways]` | 行动路径、实践建议、操作化方案 |

## 方法与公式

| Callout | 用途 |
|---|---|
| `[!proc]` | 标准操作程序、研究步骤链、方法执行流程 |
| `[!formula]` | 单个核心公式展示框；内容用等宽字体 |
| `[!formula-step]` | 一个公式步骤：公式 → 数学解释 → 结果解读 → 注意事项 |
| `[!formula-set]` | 多公式链总览，优先放 Mermaid 流程图 |
| `[!math-principle]` | 公式的数学直觉、关键性质和隐含假设 |
| `[!result-reading]` | 量化结果的正确解读、报告方式和常见误读 |
| `[!software-impl]` | 软件实现、核心包/命令、复现步骤和报告标准 |

## 批评与局限

| Callout | 用途 |
|---|---|
| `[!warning]` | 局限、风险、重要例外；只写原文明确自述的内容 |
| `[!tip]` | 理论提示、相关理论、可迁移经验 |
| `[!critique]` | 通用学术批评 |
| `[!critique-method]` | 方法论或统计错误（钢蓝） |
| `[!critique-logic]` | 逻辑或概念矛盾（紫） |
| `[!critique-data]` | 实证或数据反例（琥珀） |
| `[!critique-fatal]` | 根本性缺陷（深红，左边框加宽） |

## 导航与索引

| Callout | 用途 |
|---|---|
| `[!entry-map]` | 条目关联表（条目 / 类型 / 关系）；只写有真实关联的行 |
| `[!ref-table]` | 参考速查表（对象 / 说明 / 来源）；用于查阅，不承担论证推进 |
| `[!meta-table]` | 研究综述表，固定 5 列（研究 / 纳入 / N / d / 结论） |
| `[!framework-table]` | 理论镜头、概念工具箱；通常 2 列（工具 / 用法） |
| `[!method-panel]` | 研究设计、材料处理、分析策略；通常 2 列（环节 / 说明） |
| `[!sample-panel]` | 样本构成、材料快照；通常 2 列（维度 / 信息） |
| `[!taxonomy]` | 分类或层级体系 |
| `[!designs]` | 设计类型、研究设计或制度设计方案 |
| `[!decisions]` | 决策点、判断路径或选择标准 |

## 档案

用于人物、专著、编著、教材的固定结构档案。这类 callout 的内部结构已固定在对应模板里，不需要临时组合。

| Callout | 适用对象 |
|---|---|
| `[!person-profile]` | 人物档案三格（身份位置 / 核心角色 / 代表贡献） |
| `[!monograph-profile]` | 专著档案（核心对象 / 论证类型 / 处理粒度 / 材料边界） |
| `[!volume-profile]` | 编著档案（核心议题 / 材料边界 / 章节关系 / 使用方式） |
| `[!textbook-overview]` | 教材章节总览表 |

| Callout | 用途 |
|---|---|
| `[!strength]` | SWOT 优势（绿） |
| `[!weakness]` | SWOT 劣势（红） |
| `[!opportunity]` | SWOT 机会（蓝） |

## 引用

```markdown
> [!quote]
> 原文引用

> [!citation-card]- 引用主题
> 中文译文。[[Argument_Author_Year_Journal|(Author, Year, p. X)]]
>
> *Original text.*
```

外文材料英文原文使用斜体；中文材料附英文译文。每节最多 1–2 个 `[!citation-card]`，优先集中到页面后部。
