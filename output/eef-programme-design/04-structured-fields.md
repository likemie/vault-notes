## 建议进一步记录的字段

| 字段组 | 建议字段 | 当前材料状况 |
| --- | --- | --- |
| 研究设计 | 随机分配单位、分配比例、分层因素、对照条件 | 第二次网页可确认学校随机分配计数；详细方法待报告核验 |
| 样本流程 | 招募数、随机分配数、实际干预数、分析数、流失原因 | 现有页面样本字段尚不能完整对应这些阶段 |
| 测量 | 测验名称、版本、是否独立测验、前后测时间、长期随访 | 已有指标名称；具体工具与测量时点待核 |
| 统计结果 | 主要／次要结局、效应量类型、置信区间、p 值、校正方式 | 网页仅给出部分效应量及文字判断；缺失项保持空值 |
| 亚组分析 | 亚组定义、预先设定与否、亚组样本量、交互检验、组内效应 | 当前只能记录所列亚组及各自结果，无法推断异质性检验结论 |
| 实施过程 | 出勤、完成课时、实施依从性、人员更替、培训完成率 | 网页有文字描述，定量过程指标待核 |
| 机构分工 | 开发方、产品提供方、实施学校、独立评估机构、资助方 | 当前可区分核心角色；法律实体和研究团队成员可随报告补核 |
| 成本 | 币种、估算时间、一次性与经常性费用、摊销年限、替岗成本 | 两次试验已有不同金额与培训口径，需分别维护 |
| 资料与登记 | 研究注册号、方案、预注册分析计划、报告、附录、修订关系 | JSON 已有附件入口；研究注册信息待报告核验 |

当前项目数据中，机构名和样本字段保留各自来源；人工核对的试验信息存于 `trials[].record`。网页内容变化后，重新核对这些字段。卡片正文只显示与阅读结果有关的内容，抓取时间等维护信息留在数据层。
