# 知识库看板

在 Obsidian 里打开 [[_system/dashboard/Knowledge Dashboard|知识库看板]]，可以用快速切换器搜索 `Knowledge Dashboard` 或 `知识库看板`。

## 启用

1. 打开 **设置 → Dataview**，启用 **Enable JavaScript Queries**。此库已安装 Dataview。行内 JavaScript 查询可以继续关闭。
2. 打开 **设置 → 外观 → CSS 代码片段**，刷新列表并启用 **knowledge-dashboard**。
3. 以阅读视图或实时预览打开看板；源码模式显示查询代码。可以用 Obsidian 的书签功能收藏此页。

## 使用

- **最近活动**默认按创建时间从近到远显示，每页 20 条。切换「修改」查看最后修改的新旧笔记，切换「今天」查看当天新建或修改的笔记。点击标题打开文件，按住 Command 或 Ctrl 点击可在新标签页打开。
- **活动趋势**支持 7、30 或 90 个自然日。悬停日期查看该日总数，也可以聚焦图表后用左右方向键查看。
- **知识构成**可按类型或一级目录查看。**知识库健康**的计数可展开，逐页定位笔记。
- Dataview 索引刷新后会重新绘制看板。外部工具写入后，等文件同步并由 Dataview 索引；也可用「刷新」重新读取当前索引。看板使用 Obsidian 当前设备的本地时间。

## 统计口径

- 知识总量以 Dataview 已索引且符合 [统计配置](config.json) 的 Markdown 文件为单位。范围包含七类 Wiki 条目、文献记录、研究笔记和剪藏。根目录和其他未匹配的普通笔记归入「其他」。配置排除了模板、索引入口、原始材料、临时目录和批处理日志。
- 类型优先匹配 YAML 的 `type`，其次匹配目录。修改分类及快捷入口时编辑 `config.json`。配置无法读取时，看板暂时只统计 `wiki/` 下的笔记。
- 「今日更新」只计今天修改的旧笔记。「修改」列表和趋势均统计每个文件当前的最后修改时间。本周从周一零时开始。迁移或同步可能改变文件时间，趋势仅估算当前仍在库中的笔记。
- 「孤立笔记」在统计范围内没有来自其他笔记的入链，也没有指向其他笔记的出链。「未解析链接」以来源笔记与目标的组合计数，详情同时显示涉及几条来源笔记。两项均使用 Obsidian 的链接缓存。
- 「缺少必需字段」仅检查配置列出的七类 Wiki 字段。文献记录、剪藏和其他类型暂不做字段检查。看板只读取索引和配置。
